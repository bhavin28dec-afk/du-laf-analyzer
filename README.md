## 🚀 GitHub Pages pe Publish Kaise Karein

### Step 1 — Repository Banayein

1. [github.com](https://github.com) pe jaayein aur login karein
2. Top-right mein **`+`** → **New repository** click karein
3. Repository name dein: `du-laf-analyzer` _(ya koi bhi naam)_
4. **Public** select karein ✅
5. **"Add a README file"** checkbox **mat** check karein
6. **Create repository** click karein

---

### Step 2 — Files Upload Karein

1. Naye repository page pe **"uploading an existing file"** link pe click karein
2. `index.html` aur `README.md` dono files drag & drop karein
3. Neeche **"Commit changes"** click karein

---

### Step 3 — GitHub Pages Enable Karein

1. Repository page pe **Settings** tab pe click karein
2. Left sidebar mein **Pages** pe click karein
3. **Source** section mein:
   - Branch: **`main`** select karein
   - Folder: **`/ (root)`** select karein
4. **Save** click karein

---

### Step 4 — Live Link Milega ✅

Kuch seconds/minutes mein aapka link ready ho jaayega:

```
https://YOUR-USERNAME.github.io/du-laf-analyzer/
```

> ⏳ Pehli baar publish hone mein 1-2 minute lag sakte hain

---

## 🔗 Share Karne Ka Tarika

Ek baar GitHub Pages live ho jaane ke baad:

1. Dashboard pe Excel file upload karein
2. **"⚙️ Process Data"** click karein
3. Dashboard render hone ke baad **"🚀 Publish & Share"** button click karein
4. Title, Author, Period fill karein → **"Generate Link"**
5. Jo link milega — woh kisi ko bhi WhatsApp/Email pe bhej sakte hain
6. Link open karte hi unhe poora dashboard dikhega — **bina koi file upload kiye!**
